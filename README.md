# PlatePal
### *Search, filter, and save delicious recipes all in one simple app.*

PlatePal is a simple, modern recipe discovery app built with Next.js.  
Users can search for recipes, filter by categories, and save their favourites — all inside a clean, intuitive interface.

This project is designed for learning, collaboration, and showcasing front‑end development skills.

---

## Features

- Recipe Search — find recipes by name or ingredient  
- Category Filters — browse by meal type or tags  
- Favourites System — save recipes for quick access  
- Responsive UI — works on desktop and mobile  
- Reusable Components — modular, maintainable codebase  
- API Integration — fetch recipes dynamically  

---

## Tech Stack

- Next.js (App Router)  
- React  
- TypeScript  
- CSS Modules / Global Styles  
- Node.js
